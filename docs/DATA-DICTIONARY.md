# 功率与限电定义

设备额定功率为kW。遥测kW与MW统一为kW，辐照度为W/m²。样本时刻须带偏移，统一UTC。记录代表自采样时刻起600秒的左值保持区间，超过600秒不外推，缺测保持未定。
每台设备重叠或相邻限电事件先求并集，再按遥测及有效期边界切分半开区间。样例INV-A的10:00–10:20及10:10–10:30合并为30分钟，不能重复积分重叠10分钟。
基线只采用同区域、同采样时刻、同100W/m²辐照档、健康且不处于限电中的参考逆变器；至少2台。对参考功率按各自额定功率归一，取中位数再乘目标额定功率，基线不超过目标额定功率。无合格对照返回NO_REFERENCE及null损失，不填0。
每片段损失=max(基线−实际,0)×秒数/3600。实际高于基线时损失0。计算保留Decimal精度，汇总后统一保留0.0001kWh；未定时长单独展示，不并入已确定损失。
清批INV-A基线100kW、实际60kW、并集30分钟，损失20kWh；INV-B基线50、实际30、20分钟，损失6.6667kWh。总确定损失26.6667kWh。能量核验按实际+非负损失计算可解释基准电量。
同设备同一时刻不同观测全部隔离；同值重复观测保留稳定编号。封存需无隔离和未定片段。此工具供离线复算，不包含生产控制或电网调度。

# 储能回补裁定（M6）

配套储能以 `STORAGE` 记录接入，沿用左值保持口径：自采样时刻起 `cadence_seconds` 秒，电量=功率×秒数/3600。储能设备在 `context.devices` 标记 `storage:true` 并给 `round_trip` 循环效率；状态仅允许 `限电充电/常规充电/储能自用/储能上网`，非法状态隔离。

毛损失维持第五条基线差额口径，日内先确认，不因储能改写。回补按以下顺序裁定，逐笔留痕：

1. 充电来历分桶：充电区间与同区域限电并集求交集。交集电量进 `限电充电` 桶（受限电量，唯一可回补来源），无交集部分进 `非限电充电` 桶；一笔充电跨在限电边界上时拆为 `混合充电`，两桶各记一部分。
2. 放电追溯：放电量先乘 `round_trip` 折算为充入侧可追溯电量，再按时间 FIFO 从来历桶扣减。`储能自用` 只消耗限电桶、不产生回补；`储能上网` 中来自限电桶的部分才形成回补，来自非限电桶的部分不回补。
3. 损耗有去向：每笔放电的转换损耗=放电量−可追溯电量，单独列示，不计回补。
4. 待查片段：可追溯电量超过桶结余时，缺口记 `ORIGIN_SHORTAGE`，该笔放电不回补并列入待查，阻断封存；失败不删改任何已有记录。
5. 恒等式（量化到0.0001kWh后校验）：
   - 净损失 = 毛损失 − 回补上网电量
   - 限电充入 = 回补 + 自用限电 + 限电桶结余（来历守恒）
   - 非限电充入 = 非限电来源放电 + 非限电桶结余

清批储能台账：限电充入6.0000kWh，上网回补1.5000kWh，自用限电0.9000kWh，限电桶结余3.6000kWh，转换损耗0.4000kWh；毛损失26.6667kWh，净损失25.1667kWh。BESS-D 由非限电充电后上网，放电可追溯但回补0。待复核批 SD-X-40 无充分来历，缺口1.2167kWh进待查，状态保持待复核。

重试与切换安全：同输入与规则版本批号不变，`rerun` 读取不可变输入快照，不新增批次、不覆盖已复核 revision/status；切换数据集或导入失败时旧批次保留可读。封存额外要求来历守恒、净损失恒等式成立且无待查片段。
